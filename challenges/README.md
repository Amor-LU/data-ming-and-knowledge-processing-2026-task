# 挑战任务

挑战任务表格统一放在本目录，任务内容和提交要求以课堂发布为准。

## 提交挑战项目

1. 在自己的 Fork 里同步课程仓库，打开 `challenges` 目录。
2. 每组创建一个 `challenges/项目名/` 目录。项目名应在本目录内唯一。项目的 README 写明对应的挑战任务、组员、运行方法和依赖。
3. 如果项目已有独立 GitHub 仓库，可以在 README 里附上仓库链接和本次提交对应的 commit。若需要把源码一并提交到课程仓库，把源码复制进项目目录，排除子项目自己的 `.git` 目录。
4. 由一位组员代表全组向课程仓库的 `main` 分支发起一个 PR，在 **Files changed** 确认只提交了本组项目的相关变更。

Git submodule 可以用于保留独立仓库及其提交历史。它会在课程仓库中记录子项目仓库地址和一个固定的 commit，并修改根目录的 `.gitmodules`。使用前需确保阅卷老师可以访问子项目仓库。本机的软链接只记录路径，其他人克隆课程仓库时无法通过它取得子项目的代码。
