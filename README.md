# 2026 数据挖掘与知识处理 · 作业提交

本仓库使用 GitHub Pull Request（PR）收集作业。每次作业的内容、截止时间和提交要求以课堂通知为准。

## 网页提交步骤

1. 登录 GitHub，打开本仓库，点击右上角 **Fork**，再点击 **Create fork**，创建个人副本。
2. 在自己的副本里点击 **Add file → Upload files**，上传作业文件。可以先在电脑上整理好目录，再将文件夹拖入上传区域。
3. 确认文件路径和内容，填写提交说明并点击 **Commit changes**。
4. 点击 **Contribute → Open pull request**。确认目标仓库为 `wang-h/data-ming-and-knowledge-processing-2026-task`，目标分支为 `main`，再点击 **Create pull request**。
5. 打开 PR 的 **Files changed**，确认作业文件和目录正确，保留 PR 链接。需要补交或修正时，在自己的副本中更新同一分支，原 PR 会自动更新。

## 文件放在哪里

建议使用 `submissions/<作业编号>/<GitHub用户名>/`，例如 `submissions/lab01/octocat/report.pdf`。PR 标题可用 `[lab01] octocat`，作业编号以课堂通知为准。

本仓库、Fork 和 PR 都是公开的。请勿上传学号、联系方式、账号密钥或未经许可的数据。如作业要求提交这些信息，请按课堂通知指定的渠道提交。
