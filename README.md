# 2026 数据挖掘与知识处理 · 作业提交

本仓库使用 GitHub Pull Request（PR）收集作业。每次作业的内容、截止时间和提交要求以课堂通知为准。

## 网页提交步骤

1. 登录 GitHub，打开本仓库，点击右上角 **Fork**，再点击 **Create fork**，创建个人副本。
2. 在自己的 Fork 中打开对应的实验目录（如 `exp01`），再点 **Add file → Upload files**。把装有两个作业文件的 `学号-姓名` 文件夹拖到上传区域。已经 Fork 过的同学，可以先点 **Sync fork → Update branch** 获取新目录。
3. 确认文件路径和内容，填写提交说明并点击 **Commit changes**。
4. 点击 **Contribute → Open pull request**。确认目标仓库为 `hint-lab/data-ming-and-knowledge-processing-2026-task`，目标分支为 `main`，再点击 **Create pull request**。
5. 打开 PR 的 **Files changed**，确认本次提交只包含自己目录里的两个作业文件，保留 PR 链接。需要补交或修正时，在自己的副本中更新同一分支，原 PR 会自动更新。

## 作业目录

四次实验分别提交到 `exp01`、`exp02`、`exp03`、`exp04`。每位同学在对应的实验目录下创建一个以 `学号-姓名` 命名的文件夹。学号和姓名之间用半角连字符 `-`。

每次作业只提交以下两个文件：

- `main.py`：放本次作业的核心代码。
- `reflection.md`：用自己的话亲自写一段感想，可以谈自己学到了什么，或者遇到并解决了什么问题。

例如，学号为 `00000000`、姓名为「示例同学」的同学可以这样整理（以下为虚构示例）：

```text
exp01/
└── 00000000-示例同学/
    ├── main.py
    └── reflection.md
```

仓库、Fork 和 PR 都是公开的，目录名中的学号和姓名也会公开可见。请勿在作业中附带联系方式、账号密钥或未经许可的数据。
